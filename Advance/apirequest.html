Value State Description 0 UNSENT Client has been created. open() not called yet. 1 OPENED open() has been called. 2 HEADERS_RECEIVED send() has been called, and headers and status are available. 3 LOADING Downloading; responseText holds partial data. 4 DONE The operation is complete. EXAMPLE 🎯 Imagine you're ordering pizza online When you send a request using XMLHttpRequest, it's like ordering pizza. The readyState tells you what stage your pizza order is in. 🍕 Pizza Analogy of readyState readyState State Pizza Example 0 UNSENT You haven't placed the order yet. 1 OPENED You just called the pizza shop. 2 HEADERS_RECEIVED They accepted your order and told you price & time. 3 LOADING They're making your pizza. It's in progress. 4 DONE Pizza has arrived. You can eat now! 🍕
